提交与评论

双方使用同一证据标准：至少提供可核对截图，清楚说明会话是否新建、上下文是否干净、测试提示词和观察结果。评论针对材料，不针对个人。

最低提交门槛

  • 至少一张截图；仅口述不接受
  • 标明支持或反对哪项结论
  • 说明 session、时间和上下文状态
  • 视频、原始会话或日志优先
本页当前为纯静态原型。提交内容和附件仅保存在本浏览器的 IndexedDB 中，不会自动上传服务器；同一设备可继续查看和下载。公开版建议使用 GitHub 登录、Cloudflare Worker 签发短期上传凭证、R2 存附件、D1 存证据元数据，并使用 giscus 承担公共评论。
