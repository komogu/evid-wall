灰测路由
证据链墙

将帖子中的接口字段、统计图、同会话差异、可重复输入规则和原始 session 串成一条可审阅的链。现有材料最支持：7 月与 8 月不是同一模型路径；8 月强指向 Claude 请求链，Opus 5.0 是大概率候选。

阅读规则

页面只保留可公开复核且符合本页范围的材料。图片本身、作者解释和型号归因分别评级。

  • 高置信度：确定性规则、可量化字段、同会话对照
  • 中高置信度：多项独立线索汇合
  • 中及以下：知识、文风、自述、单次行为
先排除一个常见误区：模型不能接受文件或图片，不是反路由的有力证据。网关可以在模型调用前拦截、清洗或不转发附件；该现象只能证明产品链路未把附件交给模型。

能力归因同样接受反证：任何认为灰测模型能力明显高于 Fable 系列或 Opus 5.0 的论断，都可以提交同提示词、干净会话、可复现截图或原始记录。本页不会用主观观感封死候选。

前端任务可作为有限能力对照：现有外部样例中，标注为 Opus 5.0 的前端效果整体强于 Fable 对照；这只能作为能力上界与候选排序参考，不能单独确认灰测型号。

02 / Premises

读懂对照前的必要前提

这里定义的是本报告如何识别路径切换，不是靠文风猜模型。

P01 / GREY PATH

灰测基准：总结式思维链，分段输出

稳定灰测 session 的主要可观察特征，是先生成内部推理，再把摘要按较大的文本块分段输出。它与公开版逐 token 流式思维链的时序和 chunk 形态不同。

P02 / FALLBACK

生物安全触发：长 TTFT 后回退流式路径

生物甲触发后不是简单空回，而是经历明显更长的 TTFT，随后出现 DS 风格逐 token 流式思维链；该 session 此后失去灰测，符合回退到 0813 V4 Pro 正式版。

P03 / CONTEXT

污染后的公开 DS 不能承担反证

当公开 DS 已在上下文中读到上文示例、角色说明或脏 token 时，它可以模仿上文输出；同理，后续没有再次触发某类安全行为，也不能反推先前路由不存在。需要新会话、干净上下文和同提示词对照。

证据规则：大部分关键实验都有视频或原始会话记录，可按需提供。任何正面或反面主张，至少应附可核对的截图；仅凭口述不进入证据链。更强的材料应包含完整会话、时间线、请求日志或视频。

04 / Chain

完整证据链

每个节点只写它能直接支持的最窄结论。最终型号判断来自多节点汇合。

高
E01 · JULY

固定 64-token 缓存重算

旧灰测中 cache miss 稳定小于 64，cache hit 为 64 的整数倍，并符合 hit=floor(input/64)×64。正常推理服务应返回实际缓存数据，而不是把输入长度机械拆成 64 粒度。

直接支持7 月 usage/cache 字段经过特殊重算，处理链与普通 DS 不同。
不能支持不能由此命名上游；不能套用到 8 月新灰测。
“所有非 cache 的 input token 全都小于 64”“命中 = 下取整(input/64)×64”“8 月明显假的缓存数据修好了”
高
E02 · JULY

TTFT、缓存合法性、推理速度共同聚类

低 TTFT 组约 200 字符每秒且缓存较正常；高 TTFT 组约 80 字符每秒并伴随异常缓存。证据价值来自三个维度同时分组，而不是单看首字延迟。

直接支持7 月至少存在两类处理链或推理基础设施，不只是同一基础设施换权重。
限定排队可以解释 TTFT，不能解释缓存与速度同步聚类；统计不能直接命名模型。
中高
E03 · JULY

reasoning token 对可见推理文本重计数

返回的 reasoning token 严格等于可见思维链用 DS tokenizer 计数后的长度加 2。结合缓存字段异常，更像把上游可见摘要经 DS tokenizer 重新计量后返回。

直接支持usage 字段存在 DS 侧重计数，符合协议转换层。
限定计数关系本身不能确认摘要来源，也不能识别具体上游。
中高
E04 · JULY

API 能力与标识行为不同

非灰测路径可返回 logprobs，灰测相应字段为空；system fingerprint 初期与公开 V4 Flash/Pro 不同，后来又被统一为 V4P 标识。流式 delta 也呈整段文本与异常中文边界。

直接支持两条路径的底层 API 能力、流式封装或后端配置不同。
限定字段可由服务策略或代理层修改，需与缓存和统计证据合看。
高
E05 · AUGUST

antml 形成确定性的请求预处理规则

未转义标签被剥离；重复叠加前缀后输入 token 不增加；修改中间一处后从首个不匹配位置开始输出；规则对大小写不敏感。mitu9527 与另一参与者分别复现。

直接支持8 月请求在模型 tokenization 之前或协议层经历 Claude 风格解析，强指向 Claude 请求链。
限定兼容层可以主动复刻规则；不能仅凭此证明直连官方 API 或确认具体型号。
技术展开：为什么纯“蒸馏学到脏 token”解释不成立
  1. 权重不能改变输入计量。如果标签作为普通文本进入模型，就应先被 tokenizer 计入输入 token。模型怎样生成都不能反向让已计量字符消失。
  2. 大小写通常改变 token 序列。antml、ANTML 与混合大小写通常对应不同 token ID 或切分。被动蒸馏不会自然获得覆盖任意大小写组合的统一规则。
  3. 首个不匹配位置是程序边界。“逐段识别、剥离、遇到不匹配停止”更像确定性解析器状态机，不像概率性的 next-token 生成。
  4. 多项观测都发生在生成之前或之外。输入 token、大小写规范化与固定边界共同定位到预处理或协议解析层。

仍保留的解释：第三方兼容层可人工实现同样规则。所以它证明请求链特征，不证明调用渠道。

高
E06 · AUGUST

fork 新会话掉灰测，原 session 继续保留

同账户、同一时间，原 session 继续聊天仍保留灰测；fork 出来的新 session 变为公开 DS 路径。

直接支持路由状态绑定会话，而非简单绑定账户或所有新请求。
限定这能证明 session 级路由，不识别上游身份或路由动机。
“fork session 会掉灰测”“原 session 继续聊还会在”“fork 的变成了 DS”
高
E07 · AUGUST

生物安全请求后 fallback 到 0813 V4 Pro 正式版

稳定灰测 session 在生物安全请求后转为逐 token 流式思维链，随后不再回到灰测。另一名测试者复现约 15 秒 TTFT 后切为 DS 流式路径。原始 session 中 provider/model 标签始终相同，差异体现在时序、输出形态和会话状态。

直接支持灰测上游在该类请求处被拒绝或中断，产品随后回退到 0813 V4 Pro 正式版路径。
限定单一生物题不是模型指纹；T4 噬菌体反例说明处理取决于具体风险与上下文。
“思维链变成流式了”“一问生物甲就没了”“首字 15 秒，切了 DS 流式思维链”
中高
E08 · AUGUST

摘要块式、逐 token 与 tokenizer 特征指向多条输出路径

灰测可见摘要块式思维链，公开版逐 token 输出；部分会话的分词或 chunk 边界与公开 DS 不同。该组与 fallback、fork 和 antml 证据相互补强。

直接支持存在不同流式封装、分词或输出处理路径。
限定截图缺少完整原始 SSE chunk；文风或视觉分块不能单独识别模型。
中
E09 · CROSS-ROUND

公开版反测须使用干净上下文

干净会话中的公开版并非所有脏 token 都能通过，二十余次未复现正文固定输出；简单问题也没有像旧灰测那样自动不开思考。若 DS 已经在上下文中看过上文示例、角色说明或目标 token，它可以沿用措辞并模仿输出，这种“上下文污染后复现”不能反驳干净会话中的差异。后续未再次出现某类安全行为，同样不能反推先前没有路由。

直接支持干净会话下，7 月灰测与后续公开版的 tokenizer、后训练或服务策略不同。
反证门槛应在全新 session、同参数、同提示词下复现，并至少提供完整截图；只有口述或污染后的续写不算。
中
E10 · AUGUST

知识题仅用于候选排序

灰测知道 2025 年 6 月、2025 年 10 月信息，并在秘鲁总统题回答 José Jerí。作者本人同时说明“知识库没法锤”。

直接支持知识表现可用于缩小候选，为 Opus 5.0 判断提供有限旁证。
限定联网、检索、后训练和提示上下文都会影响答案；不能据此排除 Fable 5 或确认 Opus 5.0。
中高

07 / Boundaries

必须保留的边界

边界不是削弱证据，而是防止窄事实被升级成过度归因。

64-token 缓存只属于 7 月。8 月的新灰测明确记录旧的异常缓存数据已经修复。
antml 强指向 Claude 请求链，不等于直连官方 API。中转或兼容层可主动复刻规则。
大小写无关排除的是纯蒸馏解释。它不能排除有人写了大小写不敏感的解析器。
“能输出标签”没有鉴别力。Claude 与 DS 都可在适当转义或普通文本形式下输出；关键是未转义输入的确定处理。
知识题不能确认 Opus 5.0，也不能排除 Fable 5。型号判断必须合并请求链和系统行为。
TTFT 不是单项模型指纹。它只有与缓存合法性和推理速度共同聚类时才有较高价值。
模型自述和文风只作背景。系统提示、角色注入、蒸馏和后训练均可改变表面输出。
文件能力不构成强反证。附件可能在网关处被拦截、清洗或不转发。
8 月生物安全请求不是直接空回。观测到的是长 TTFT 后转为 DS 风格流式输出，并导致 session 失去灰测。
上下文污染后的模仿不能作为反证。公开 DS 已读到上文内容后可沿用目标 token、角色或论证框架；缺少新会话同提示词对照时，没有独立鉴别力。
后续未再触发某类安全行为不否定先前路由。需要控制上下文、会话状态和具体提示词，不能仅凭一次续聊推翻前序记录。
调用渠道、托管方式与动机未知。技术材料不证明商业关系、数据用途或部署方式。
08 / Method

样本与收录规则

样本范围

基于本地 archive.dht 镜像。完整审阅 N一串 211 条、楼主 237 条消息，并补入 mitu9527 的独立 antml 复现、生物安全 fallback 记录与原始 session。

本页仅收录当前证据链所需材料，外部消息跳转已全部移除。多数关键实验另有视频或原始会话记录，可按需提供。

收录原则

  • 截图与可量化字段优先于口述。
  • 任何支持或反对主张至少附一张可核对截图；仅凭口述不进入证据链。
  • 同一实验的连续图片按证据簇排列。
  • 重复转发、梗图、动机争论不计入。
  • 反例必须控制会话、上下文和提示词；污染后的模仿不承担独立反证。
  • 置信度评价材料对窄结论的支持强度，不评价发言者。
