# Evidence Wall

公开证据链墙与正反证据提交页面。

- 在线浏览：<https://evid-wall.mitu233333.workers.dev>
- 证据提交与评论：<https://evid-wall.mitu233333.workers.dev/discussion>

## 文件

- `index.html`：证据链墙
- `antml-analysis.html`：ANTML 动机与蒸馏分析原文
- `discussion.html`：证据提交、附件下载、图片放大和公共评论
- `src/worker.js`：服务端接口
- `schema.sql`：数据结构

部署配置、资源标识和账户信息不保存在公开仓库中。
